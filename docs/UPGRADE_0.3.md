# 0.3 账号、学习与处置升级

本轮以《功能改进建议》的 A1、B1/B2、C1 为优先范围，增加个人账号与执行权限，保留现有事件数据和离线诊断能力。

## 已实现

| 建议 | 实现 | 边界 |
| --- | --- | --- |
| A1 多事件关联 | 时间窗口、共同实例或同服务同类型生成关联分组，展示关联依据并链接原事件 | 标签关联是候选线索，不能证明共同根因；环境、演示数据隔离，未知标签不作为依据 |
| B1 历史案例 | 真实事件填写处置记录并标记解决后自动保存和回灌检索 | `personal` 可信等级，候选根因、人工记录与健康核查分别保存，不自动晋升已审核知识 |
| B2 效果反馈 | 每个账号每次诊断可更新有用/没用反馈，统计真实建议有用率 | 不等价于根因准确率；至少三条反馈且负面超过一半的知识标记待复核 |
| C1 白名单执行 | 匹配剧本、生成计划、高级账号审批、固定执行器动作、独立恢复核查及审计 | 仅最高等级不超过 warning 的事件；不执行模型命令；真实操作需要接入执行器 |
| 账号分级 | 观察员、初级、高级、管理员；登录、会话撤销、账号管理 | 共享兼容令牌只有手动/只读权限；暂不包含 SSO/MFA、服务级多租户授权 |

## 使用流程

1. 本机首次打开工作台，在账号入口初始化管理员。没有默认密码。Docker 使用 README 中的交互初始化命令。
2. 管理员在账号管理创建观察员、初级或高级工程师，分别登录后查看权限变化。
3. 注入“低等级缓存告警”，后台会从文件发现 warning 事件并完成诊断。
4. 高级账号在事件处置页生成计划，核对目标、剧本审核人、回滚步骤和十分钟有效期，确认执行。
5. 内置演示结果为 `simulated`，健康状态为未知；真实 HTTP 剧本会查询健康接口，但不会自动标记事件解决。
6. 人工解决真实事件时填写处置记录，历史案例进入知识检索；反馈在知识质量页汇总。

## 真实执行器协议

从 `config/remediation.example.json` 创建服务端真实配置，设置 `REMEDIATION_CONFIG_PATH`。配置使用固定服务、环境、实例、来源和故障类型，不支持用户提供 URL、命令或动态 shell 插值。动作类型为 `cleanup_managed_temp`、`restart_stateless_workload` 或 `switch_standby`；具体实现由独立执行器提供。低告警等级不保证动作安全，剧本必须经服务负责人审查，只授权可逆、范围受控的操作，并落实回滚。

执行器必须使用 HTTPS，本机开发可使用回环 HTTP。密钥通过 `token_env` 引用环境变量，不写入计划或审计。Agent 不跟随重定向、不自动重试操作。建议执行器同时检查服务身份、动作范围、目标状态，并持久化幂等键。

执行接口接收 `POST`，包含 `Idempotency-Key` 头和结构化 JSON：

```json
{
  "action": "cleanup_managed_temp",
  "target": {"service": "orders-api", "environment": "staging", "instance": "worker-01"},
  "parameters": {"policy": "rebuildable-cache-only", "max_age_hours": 24},
  "incident_id": "incident-id",
  "plan_id": "plan-id"
}
```

返回 `{"status":"succeeded"}` 或 `{"status":"failed"}`。超时、无效或非成功 HTTP 响应视为结果未知，不自动重放；同目标存在未知执行结果时，其他计划也会被阻止，需要人工在执行器侧核对。

核查接口接收 `GET`，查询参数是 `plan_id/service/environment/instance`，需返回：

```json
{
  "plan_id": "plan-id",
  "healthy": true,
  "checked_at": "2026-10-02T08:00:00+00:00"
}
```

核查时间必须有时区、晚于操作开始且为最近一分钟的数据；必须返回对应计划和布尔健康状态。数据缺失或无效保留健康未知。检测到告警升级、诊断变更、事件合并/拆分、配置变化或过期时，审批计划失效；同事件不重复执行，同目标十分钟内限制重复操作。执行开始后的新告警仍可能出现，工程师应结合现场指标确认恢复。

## 持久化与部署

原 SQLite 事件库只增加关联学习和处置表；账号单独保存于 `accounts.sqlite3`。密码存带盐 scrypt 哈希，会话仅存 SHA-256 摘要，有效期八小时；停用、密码或等级变更撤销现有会话。最后一个有效管理员不可降级或停用。

首次管理员只能从真正本机回环请求或本机 CLI 创建。开启个人账号后，匿名访问不能回退为本机操作员。保留旧令牌兼容，但不会授予高级或管理员权限。非本机部署使用 HTTPS 传输登录信息。保持单进程运行；此迭代不改变采集器单 worker 部署要求。
