## 使用边界

系统只监听已经登记且当前主机可访问的文件，不会自动发现所有服务器，也不会直接连接 Kubernetes API。集群故障可通过 Events/Pod 日志文件和告警进入相同链路；需要现有采集器提供数据。

本地置信度是日志模式及知识匹配的启发式分值，不是统计校准后的概率。故障现象与最终根因不能混同，重复相同报错不会增加独立证据。没有上下文的诊断需要现场验证，恢复检查不会以日志沉默为健康证明。

单进程 SQLite 与本地文件适用于开发、演示和小规模验证。当前未证明 99.9% 高可用或 PRD 中的 Top1/Top3 准确率目标；正式投产前应基于真实故障样本评估，拆分采集和任务队列，接入身份系统及集中审计。
